# Overview

This directory is the stable entry point for understanding Vermay as a whole.
It describes project position, repository organization, and primary request
flows without tracking active implementation progress.

## Reading Order

1. [project-position.md](project-position.md)
2. [repository-map.md](repository-map.md)
3. [request-flow.md](request-flow.md)
4. [../architecture/current-system.md](../architecture/current-system.md)

## Scope

Use this directory for low-frequency, project-wide facts. Runtime milestones,
temporary limitations under active work, and dated review evidence belong in
[../dev/](../dev/README.md).

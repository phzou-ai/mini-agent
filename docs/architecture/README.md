# Architecture

This directory owns stable architectural boundaries and vocabulary.

## Reading Order

1. [current-system.md](current-system.md) - implemented full-stack architecture.
2. [lifecycle-and-state.md](lifecycle-and-state.md) - identities, lifecycle
   ownership, status projection, interruption, and continuation.
3. [agent-os-evolution.md](agent-os-evolution.md) - conditional long-term
   direction and complexity guardrails.

## Authority

`current-system.md` describes the implementation that exists now.
`lifecycle-and-state.md` is normative for state ownership. The Agent OS document
is strategic and must not be interpreted as authorization to add speculative
services or infrastructure.

Active milestone status belongs in [../dev/runtime/](../dev/runtime/README.md).
